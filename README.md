## Editing

- `data.json`: profile, research interests, education, and skills.
- `index.html`: home news and research/project summary cards.
- `about.html`: About Me text.
- `research-experiences.html`: research descriptions and images.
- `project-experiences.html`: project details.
- `publication.html` and `activities.html`: publications and activities.
- `css/style.css` and `css/inner-pages.css`: appearance.

Commit and push changes to `main` to deploy with GitHub Pages. Search-engine exclusion metadata is intentionally retained; the website is still publicly accessible.
